# Сайт Maya Cake — інструкція

Сайт кондитерської Maya Cake: 9 сторінок, 79 позицій, 36 смаків макарон, кошик, конструктор коробки, оформлення замовлення.
Усе зроблено на чистому HTML/CSS/JS — без програм, які треба встановлювати для роботи сайту.

---

## 1. Як відкрити сайт на своєму комп'ютері

1. Відкрийте папку `maya-cake` у Finder.
2. Двічі клацніть файл **`start-site.command`**.
   - Якщо Mac пише «неможливо відкрити, розробник не встановлений» — клацніть правою кнопкою → **Відкрити** → **Відкрити**. Це треба зробити лише один раз.
3. Відкриється браузер із сайтом (`http://localhost:8000`). Вікно Терміналу не закривайте, поки дивитеся сайт.
4. **На телефоні** (телефон і ноутбук в одній Wi‑Fi мережі): у вікні Терміналу є рядок «Щоб відкрити на телефоні…» з адресою на зразок `http://192.168.1.5:8000` — наберіть її в браузері телефона.
5. Щоб зупинити — закрийте вікно Терміналу.

> Чому не можна просто двічі клацнути `index.html`? Браузер у такому режимі не дає сайту прочитати файл з товарами — і каталог буде порожній.

**Корисні сторінки для перевірки:**
- `http://localhost:8000/tools/preview.html?page=index.html` — сторінка одразу на трьох екранах (375, 414 і 768 px).
- `http://localhost:8000/tools/test.html` — автоперевірка: сайт сам проходить дедлайн, кошик, фільтри й оформлення замовлення Увага: очищає кошик у цьому браузері. Якщо довго «Перевіряємо…» — запустіть частинами: `test.html?part=1` (дедлайн, кошик, фільтри, оформлення) і `test.html?part=2` (ширини екрана).
- `http://localhost:8000/styleguide.html` — кольори, шрифти й увесь каталог на одній сторінці.
- Будь-яка сторінка з `?now=2026-11-06T15:00` в кінці адреси — сайт «думає», що зараз саме цей час у Києві (зручно показати власниці логіку дедлайну). Щоб повернути справжній час — `?now=off`.

## 2. Де що змінювати

Усі зміни — у двох файлах. Відкривайте їх у VS Code (або будь-якому текстовому редакторі), після змін збережіть файл і оновіть сторінку в браузері.

### Контакти, дедлайн, зони доставки, ціни макарон, опт → `js/config.js`

| Що змінити | Що шукати у файлі |
| --- | --- |
| Телефон, Instagram, Telegram | `PHONE`, `PHONE_LABEL`, `INSTAGRAM`, `TELEGRAM_USERNAME` |
| Дедлайн 14:00 | `CUTOFF_HOUR: 14` |
| Час доставки 10:00–18:00 | `DELIVERY_WINDOW` |
| Свята й вихідні цеху | `CLOSED_DATES: []` → наприклад `['2026-12-31', '2027-01-01']` |
| Вартість доставки й поріг | у списку `ZONES`: `fee` — ціна доставки, `freeFrom` — безкоштовно від |
| Дні доставки для міста | `days`: 0 — неділя, 1 — понеділок … 6 — субота. Наприклад, `days: [3, 0]` — середа й неділя |
| Додати місто | скопіюйте рядок будь-якого міста в `ZONES`, змініть `id` (латиницею), `label`, ціни й дні |
| Ціни макарон за штуку | `MACARON_PRICES: { classic: 55, p100: 100, p120: 120 }` |
| Розміри коробок | `MACARON_BOXES` |
| Подарункова коробка | `GIFT_BOX_PRICE: 45` |
| Оптові ціни й РРЦ | `B2B` → `items` (`opt` — опт, `rrp` — рекомендована роздрібна) |
| Максимум однієї позиції в кошику | `MAX_QTY: 20` |

Рядки з позначкою `УТОЧНИТИ` — дані, які ще треба підтвердити у власниці.

### Товари → `data/products.json`

Кожен товар — це блок у фігурних дужках `{ … }`. Головні поля:

| Поле | Що означає |
| --- | --- |
| `"name"` | назва |
| `"price"` | ціна в гривнях (`null` — «ціну уточнюйте» і кнопка «Запитати в Telegram») |
| `"weight"` | вага й розмір, як показати на сайті |
| `"description"` | опис |
| `"contains"` | склад / алергени (рядок «А!» зі сторіз) |
| `"allergens"` | іконки алергенів: `gluten`, `milk`, `eggs`, `nuts`, `peanuts`, `sesame` |
| `"kbzhv"` | білки, жири, вуглеводи, ккал на 100 г |
| `"shelfLife"` | термін придатності |
| `"tags"` | `"new"` — позначка «Новинка», `"gift"` — потрапляє в «Подарунки» |
| `"variants"` | варіанти з різними цінами (начинки бенто, набори трайфлів) |
| `"check"` | нотатки «що уточнити» — на сайті не показуються |

- **Порядок товарів** у файлі = порядок «Популярні» в каталозі.
- **Добірка «Радимо спробувати»** на головній — список `FEATURED` на початку файлу `js/index.js`.
- **Смаки макарон** — у кінці файлу, розділ `"macarons"`.
- Будьте уважні з комами й лапками: після кожного поля, крім останнього в блоці, ставиться кома. Якщо після зміни каталог став порожній — найімовірніше, загубилась кома чи лапка. Перевірити файл можна на jsonlint.com (вставте вміст → «Validate JSON»).

### Тексти сторінок

Тексти — прямо в HTML-файлах (`index.html`, `about.html` тощо): знайдіть потрібну фразу пошуком (⌘F) і замініть.

### Фото

Фото вирізані з макетів сторіз у папці `materials/photos` (1206×2144 px) скриптом `tools/process_images.py`: він прибирає текст, ціни й лінії-вказівки, кадрує десерт у 4:5 і окремо вирізає коло з розрізом. Перезапустити обробку всіх фото:

```
python3 tools/process_images.py
```

Якщо колись з'являться окремі фото (не макети сторіз):

1. Створіть папку, наприклад `originals`, і покладіть туди фото з назвами як у `data/products.json` (поле `"id"`):
   - `berry-plombir.jpg` — основне фото (обріжеться по центру до формату 4:5);
   - `berry-plombir-cut.jpg` — фото розрізу (обріжеться в коло).
2. Відкрийте Термінал у папці `maya-cake` і виконайте:
   ```
   python3 tools/process_images.py --originals originals
   ```
3. Сайт одразу покаже нові фото (у ширинах 400 і 800 px).

(Для скрипта потрібні бібліотеки: `python3 -m pip install --user Pillow numpy scipy`.)

## 3. Як підключити Formspree (щоб замовлення приходили на пошту)

Зараз сайт працює в **демо-режимі**: замовлення оформлюється, але нікуди не надсилається — на сторінці «Дякуємо» людина бачить кнопку «Надіслати замовлення в Telegram».

1. Зайдіть на **formspree.io** → **Get Started** → зареєструйтеся на пошту, куди мають приходити замовлення (пошта власниці).
2. Підтвердіть пошту (прийде лист).
3. Натисніть **+ New Form** → назва «Замовлення Maya Cake» → **Create Form**.
4. Formspree покаже адресу на зразок `https://formspree.io/f/xyzabcde`. Скопіюйте **лише код після `/f/`** — тут це `xyzabcde`.
5. Відкрийте `js/config.js` і вставте код:
   ```js
   FORMSPREE_ID: 'xyzabcde',
   ```
6. Для заявок кав'ярень створіть другу форму (наприклад, «Опт Maya Cake») і вставте її код у `FORMSPREE_B2B_ID`. Можна вставити той самий код, що й для замовлень.
7. У налаштуваннях форми на Formspree:
   - **Settings → Restrict to Domain** — впишіть адресу сайту з Netlify (захист від чужих заявок);
   - **Settings → Autoresponse** (якщо доступно у вашому тарифі) — лист покупцю «Ми отримали ваше замовлення».
8. Перевірте: оформіть тестове замовлення — лист має прийти протягом хвилини. Перший лист може потрапити в «Спам» — позначте «Не спам».
9. Перевірте на сайті Formspree, скільки заявок на місяць дає безкоштовний тариф.

Токени Telegram-ботів у сайті не використовуються (їх було б видно всім). Автоматичні повідомлення в Telegram — окрема платна доробка.

## 4. Як викласти сайт в інтернет (Netlify)

1. Двічі клацніть **`make-deploy.command`** у папці `maya-cake`. Поруч з'явиться папка **`maya-cake-deploy`** (~4 МБ) — у ній лише файли сайту, без скрінів з Instagram і технічних сторінок.
   - **Не перетягуйте в Netlify саму папку `maya-cake`**: у ній лежать `materials` (~190 МБ скрінів), і вони стали б доступні всім.
2. Зайдіть на **app.netlify.com** → зареєструйтеся (можна через Google).
3. **Add new site → Deploy manually**.
4. Перетягніть папку **`maya-cake-deploy`** у вікно браузера.
5. Через хвилину Netlify дасть адресу на зразок `https://random-name-123.netlify.app`.
   - Змінити назву: **Site configuration → Change site name** → наприклад `maya-cake` → адреса стане `maya-cake.netlify.app`.
6. **Оновити сайт після змін:** знову двічі клацніть `make-deploy.command` → у Netlify відкрийте сайт → вкладка **Deploys** → перетягніть нову папку `maya-cake-deploy` у поле внизу сторінки.
7. Власний домен (наприклад `mayacake.com.ua`) — **Domain management → Add a domain**, далі Netlify підкаже, що вписати в налаштуваннях реєстратора домену.

## 5. Як побудовано сайт (коротко)

```
index.html      головна              b2b.html        для кав'ярень
catalog.html    каталог з фільтрами  delivery.html   доставка й оплата
product.html    картка товару        about.html      про нас
box.html        конструктор коробки  checkout.html   оформлення
                                     thanks.html     дякуємо
css/style.css   увесь дизайн (кольори — на початку файлу, розділ 1)
js/config.js    налаштування         js/cart.js      кошик
js/main.js      шапка, футер, дедлайн, картки товарів, анімації
js/*.js         логіка окремих сторінок
data/products.json   усі товари
assets/img/     фото (WebP)          assets/icons/   іконки
tools/          скрипт обробки фото, перегляд на екранах, автоперевірка
```

- **Кошик** зберігається в браузері покупця й не зникає після перезавантаження.
- **Час** рахується за Києвом, а не за годинником телефона.
- **Самовивіз** поки прибраний — повернемо, коли буде адреса точки.

## 6. УТОЧНИТИ У ВЛАСНИЦІ

**Ціни**
1. **Роздрібні ціни макарон.** У сторіз: класичні 55 грн, преміум 100 і 120 грн. Але опт для кав'ярень — 60 грн (РРЦ 80) для класичних, тобто роздріб дешевший за опт. Які ціни зараз актуальні?
2. **Трайфли (червоний оксамит, медівник, шоколад-карамель, ягідний):** 210 грн — це за 1 шт чи за набір? Зараз на сайті: набір 4 шт — 840 грн, 6 шт — 1260 грн.
3. **Тістечко «персик» з вершковим кремом:** роздрібна ціна й опис (є лише опт 70 / РРЦ 95).
4. **Випічка (15 позицій: твісти, пончики, бріоші, печиво, міні пан сюїс, Blueberry puff):** ціни й алергени — у сторіз є лише опис, вага й КБЖВ.
5. **Горішки в подарунковій коробці (5 шт):** ми порахували 5 × ціна + 45 грн (295 і 220 грн) — так?

**Товари без даних** (на сайті — «фото буде», «ціну уточнюйте», кнопка Telegram)
6. Корпусне вафельне «малина» — фото, ціна, вага, опис, склад, КБЖВ.
7. Шу класичний, шу малина, шу шоколад — те саме.
8. В умовах зберігання згадані ще круасани (класичний, мигдалевий), пліє з маком, кардамонова булка, абрикосовий пиріг, даніш фіалка-смородина, хрусткий горішок з фундуком, паштейш, Cherry Poppy Roll, сінабони — чи продаються вони, і якщо так, то фото й ціни.
9. Макарон «Капучино камамбер» — є лише в таблиці складу: фото і цінова група (100 чи 120 грн)?

**Склад, КБЖВ, терміни**
10. **Сертифікат відповідності** на фото діє з 22.10.2024 до 21.10.2025 — чи є новий? (Зараз на сайті показано цей.)
11. **Бенто:** склад, алергени, КБЖВ, термін придатності.
12. **Павлова:** вага 50 г при ціні 170 грн — так і є?
13. **КБЖВ, які не сходяться:** трайфл шоколад-карамель (жири 6,1 г, але 767 ккал), трайфл ягідний (вказано 537 ккал, з білків-жирів-вуглеводів виходить ~390), Cake layers орео-чізкейк (338,04 ккал — точно як у наполеона).
14. **КБЖВ п'яти класичних макарон** (лайм-кокос, мак-малина, лимонний щербет, шоколад-маракуйя, вишня-боби тонка) у 2–2,5 раза вищі за решту — чи всі вказані на 100 г?
15. **Алергени, які, схоже, неповні:** вафельні торти (немає борошна — ми позначили глютен), Cake layers тірамісу (лише маскарпоне й вершки — ми позначили глютен і яйця через савоярді).
16. **Безлактозний чіа-пудинг:** у складі вершкове масло — чи справді він без лактози?
17. «Груша-дорблю» і «Фісташка» є і серед класичних, і серед преміум макарон з різним складом — обидва актуальні?

**Доставка**
18. **Дні доставки** у Вишневе, Бровари, Крюківщину, Коцюбинське (зараз тимчасово пн–сб).
19. Київ — справді щодня, включно з неділею?
20. Свята й вихідні цеху (новорічні дні тощо).
21. Адреса й години роботи точки — щоб повернути самовивіз і показати адресу на «Про нас».

**Матеріали**
22. Пончики, бріоші й печиво зняті на бежевому фоні, решта десертів — на білому. За бажання можна перезняти випічку на білому для єдиного стилю.
23. Історія Maya Cake від першої особи для «Про нас»; адреса закладу @etan_cake (щоб повернути самовивіз).
25. Логотип у SVG (звіримо кольори: зараз синій #105A7F узято з PNG).
26. Дозвіл використовувати фото з Instagram на сайті.
27. Пошта для замовлень (Formspree) і чи правильний Telegram для замовлень — `t.me/Maya_Cake_Kyiv`.
28. Для кав'ярень: які ще позиції є в оптовому прайсі.
